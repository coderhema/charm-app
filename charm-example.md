# Charm Application Example

Charm allows building applications through MCP. Here's what you can do:

## Using Charm MCP

Once the Charm MCP server is connected, you can:

1. Build applications through the MCP interface
2. Use Charm's HTTP API directly
3. Create AI-powered applications

## Charm Documentation

Key documentation pages:
- https://charm.ing/docs/clients - Client setup guide
- https://charm.ing/docs/build-mcp - Building with MCP
- https://charm.ing/docs/http-api - HTTP API reference

## Authentication

Your Charm token is configured in the MCP environment variable:
`CHARM_TOKEN=<your-token>`
